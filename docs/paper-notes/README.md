# Paper Notes

One analysed note per paper. Start from [`_template.md`](_template.md).

## Workflow (per paper)

1. Identify the actual research problem.
2. Explain why it is difficult.
3. Describe the contribution.
4. Record how it was evaluated (setup + metrics).
5. Identify limitations.
6. Extract explicit future work.
7. Assess whether a smaller follow-up contribution is realistic here.
8. Record how it affects our project direction.

**Do not add a paper to [../literature-review.md](../literature-review.md) as
"read" (🟢) until its note is complete.**

## Naming

`<year>-<firstauthor>-<keyword>.md`, e.g. `1990-ostrom-governing-commons.md`.
