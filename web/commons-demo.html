Common-pool resource · agent-based model

Watch a shared resource live or die

Eight agents draw from one renewable pool each round. Whether it is sustained or collapses depends on who is in the group, what they can see, and whether anyone enforces a limit. Pick a regime or adjust the dials, then press run.

This is a faithful JavaScript port of the Python engine: deterministic configs reproduce it exactly (all presets do). With decision noise or partial communication the browser's random generator differs from Python's, so those numbers are representative, not identical. The Python repository is the canonical source of the results.
