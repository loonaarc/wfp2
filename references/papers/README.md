# references/papers/ — local PDFs (git-ignored)

Drop **legitimately obtained** PDFs here (via your FH library / interlibrary loan /
open-access) and I'll read them and write full analysed notes in
[`../../docs/paper-notes/`](../../docs/paper-notes/), upgrading the abstract-level
(🟡) notes to full (🟢) ones.

Everything in this folder is **git-ignored** (see `.gitignore`) so copyrighted PDFs
are never committed. Only this README and `.gitkeep` are tracked.

## Naming convention

Name each file to match its paper-note so I can map them automatically:

```
<year>-<firstauthor>-<keyword>.pdf
```

e.g. `1990-ostrom-governing-the-commons.pdf`, `2002-fehr-gaechter-altruistic-punishment.pdf`.
